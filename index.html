What it does

Claude gets tools for the active query window's server and database, and your SQL repository.

🔎

Understands your database

Lists databases and objects, describes tables, keys, indexes and procedures, follows dependencies and runs read-only queries.

🧩

Stored procedures

Explains a procedure from its definition and dependencies, writes CREATE OR ALTER scripts, deploys and runs them when you ask.

🗺️

Diagrams

Flowcharts of procedures and ER diagrams, including relationships inferred across databases. One-click DB diagram uses no tokens.

✋

You stay in control

Changes to the database are off, ask-every-time (default) or allowed. The approval dialog shows the SQL, server, database and reason.

📝

Edits query windows and files

Rewrites, opens or executes query windows, and edits the SQL scripts in your repository folder.

📎

Attachments and history

Attach execution plans, logs, CSV files and screenshots. Every chat is saved and can be resumed later.
