# ✦ SSMS Claude Chat

**Claude, inside SQL Server Management Studio 21 / 22.** A dockable chat window that understands the database you
are connected to: it explains and writes stored procedures, runs SQL with your approval, draws ER and flow diagrams
and edits your SQL repository. You sign in with your own Claude account.

## About this repository

This is the public home of SSMS Claude Chat: documentation (served with GitHub Pages from the `main` branch),
issues and feature requests. Edit the Markdown pages and open a pull request to improve the docs; preview locally
with `bundle exec jekyll serve` or just push and let Pages build it.

To publish a new version on the site, update `latest_version` and `download_url` in `_config.yml`.
