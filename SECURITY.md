# Security policy

## Reporting a vulnerability

Please **don't** report security problems in a public issue. Instead, use
[**Report a vulnerability**](https://github.com/TanmayS0406/ssms-claude-chat/security/advisories/new) (the
**Security** tab of this repository). Only the maintainer can see the report.

Please include what you found, how to reproduce it, and the SSMS Claude Chat and SSMS versions. You'll get a reply
within a few days, and we'll keep you updated until it's fixed. With your permission, we'll credit you when the fix
is released.

## Supported versions

Security fixes go into the newest release, available from the
[download page](https://ssmsclaudechat.azurewebsites.net/). Please update before reporting.

## Security report

The code and installer are scanned on every change and every day. See the latest results in the
[security report](https://tanmays0406.github.io/ssms-claude-chat/security/).
